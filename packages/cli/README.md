# Cooee changelog CLI

Run `npx cooee-changelog` inside a GitHub repository to connect it to the
hosted Cooee onboarding flow. The CLI only opens a browser and waits for setup;
GitHub sign-in and GitHub App access are completed on `app.cooee.sh`.

Use `--repo owner/repository` when the current directory does not have a
GitHub `origin` remote. Self-hosted Cooee installations continue to use the
[Railway setup guide](https://github.com/cooeehq/cooee/blob/main/docs/self-hosting.md).
