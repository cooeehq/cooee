# Support

- For reproducible bugs, open a GitHub issue using the bug report template.
- For feature proposals, use the feature request template.
- For setup and self-hosting questions, include the relevant environment,
  Cooee version or commit, and sanitized logs.
- For suspected vulnerabilities, do not open a public issue. Follow
  [SECURITY.md](SECURITY.md) and use a private GitHub Security Advisory.

Please remove credentials, customer data, private repository content, and
production exports before attaching logs or examples.
